# xG Thesis Project

Bachelor thesis project on Expected Goals (xG) modelling using StatsBomb Open Data.

## Goal
Compare Logistic Regression and Random Forest models for xG estimation across international competitions.

## Dataset
StatsBomb Open Data:
- FIFA World Cup 2018
- FIFA World Cup 2022
- UEFA Euro 2020
- UEFA Euro 2024
